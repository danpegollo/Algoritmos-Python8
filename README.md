# Funções em Python

Repositório com exercícios desenvolvidos para praticar funções, estruturas condicionais e lógica de programação utilizando Python.

## Exercícios

### 1. Cálculo de Conta de Luz
Programa que calcula o valor da conta de energia com base no consumo e na bandeira tarifária.

### 2. Análise de Triângulos
Programa que verifica se três valores podem formar um triângulo e identifica seu tipo.

### 3. Qualidade do Ar
Programa que analisa o índice de qualidade do ar e retorna mensagens de alerta.

### 4. Simulação de Investimentos
Programa que simula o rendimento de diferentes tipos de investimento ao longo do tempo.

## Assuntos praticados

- Funções
- Parâmetros
- Retorno com `return`
- Estruturas condicionais
- Operadores lógicos
- Operações matemáticas
- Lógica de programação
